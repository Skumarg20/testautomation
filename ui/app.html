Read the MargBooks source code (optional)

The agent learns field names by opening screens in a browser — but that only covers screens it can reach. The source code knows every screen, including ones behind permissions or rare popups. Point it at the MargBooks frontend folder and it reads ids, labels and routes straight from the files.

node_modules, dist, build and .git are skipped. Each scan adds to what is already known — nothing is thrown away.

Company settings that change MargBooks

MargBooks changes shape with these. Mode of Payment on adds a window at save; Ask Bill Discount off removes the field entirely. A test that needs a setting which is off is skipped with that reason — not marked failed, because the app is fine.

Fields on a screen

Every time the agent opens a screen it records each field — its id, CSS and XPath — along with the label printed next to it. That label is what you type when writing a test, so nobody has to hunt for an id again.
